jotai-state-tree

jotai-state-tree

MobX-State-Tree API compatible library powered by Jotai's highly performant, zero-leak atomic state engine.

Get Started API Reference
npm install jotai-state-tree jotai
🌳

Structured State Tree

Organize your application state in a well-typed tree of models with clear parent-child relationships, paths, and identifiers.

📸

Snapshots & Patches

Serialize, restore, and track changes out-of-the-box. Generate standard JSON Patches for undo/redo stacks or WebSocket sync.

🔗

Lazy References

Safely link nodes in different branches of the tree by their identifiers. Resolved dynamically and lazily with compile-time type safety.

🧪

Jotai Power

Runs on top of Jotai. Enjoy granular property-level reactive updates, zero leaks, and seamless concurrent React compatibility.

⚡

MST Compatibility

Migrate effortlessly from MobX-State-Tree. Employs the same syntax structure (`types.model().views().actions()`) without the bulk.

🛠️

Fully Type-Safe

Designed from scratch for perfect TypeScript integration, inferring types directly from your runtime models.
